## Overview
A live catalogue for a wholesale plastics business. It is built with vanilla HTML, CSS and JavaScript on purpose, so it stays fast, cheap to run and deploys to Vercel with a single push.

## What it does
- Lists 200+ products with global search and a dark mode.
- Google Sheets and Drive act as the data layer, so the client updates products without a developer.
- A 6-page Apps Script admin panel handles product management.
- An automated backup runs every 2 days.
